事実：Web版（ブラウザ）を使ったアップロード手順
以下の手順は、Webブラウザから直接GitHubリポジトリにファイルを追加する標準的な操作です。
ソース: GitHub 公式ドキュメント (リポジトリへのファイルの追加)
1.リポジトリを開く:ブラウザでGitHubにログインし、作成した自分のプロジェクト（リポジトリ）のページを開きます。
2.アップロード画面へ移動:ファイル一覧の右上あたりにある「Add file」というボタンをクリックし、表示されるメニューから「Upload files」を選択します。
3.ファイルの選択:「Drag files here to add them to your repository」と書かれた点線の枠内に、パソコン上のファイルやフォルダをドラッグ＆ドロップします。（または「choose your files」をクリックして選択します）
4.コミット（記録）の実行:ファイルが読み込まれたら、画面下部の「Commit changes」という欄にある最初のテキストボックス（Summary）に、「〇〇コンポーネントの追加」といった作業内容を短い文章で入力します。
5.完了:緑色の「Commit changes」ボタンをクリックすると、アップロードが完了し、リポジトリにファイルが反映されます。


事実：GitHub Desktopを使ったアップロード手順
以下の手順は、公式のデスクトップアプリ「GitHub Desktop」を使ってローカルPCの変更をGitHubに反映させる標準的な操作です。
ソース: GitHub Desktop 公式ドキュメント (リポジトリのクローン)、(変更のコミットとプッシュ)
1.リポジトリのクローン（初回のみ）:GitHub Desktopを起動し、メニューの「File」>「Clone repository」を選択します。「GitHub.com」タブから自分のリポジトリを選び、「Local path」でPCのどこに保存するかを指定して「Clone」をクリックします。
2.PC上でのファイルの保存:ここが普段のプログラミング作業です。クローンしてできたPC上のフォルダを開き、そこに自作のRTコンポーネントのソースコード（.cpp, .py など）を保存・移動します。
3.変更の確認:GitHub Desktopの画面に戻ると、左側の「Changes」タブに先ほど保存したファイルの一覧が自動的に表示されます。（ここでチェックがついているファイルがアップロード対象です）
4.コミット（記録）:左下の「Summary (required)」というテキストボックスに「最初のコンポーネントを作成」などと作業内容を入力し、すぐ下の青い「Commit to main」ボタンをクリックします。
5.プッシュ（アップロード）:これを押して初めてWeb上のGitHubに反映されます。画面上部のメニューバーにある「Push origin」というボタンをクリックします。これでGitHubへのアップロードが完了します。
